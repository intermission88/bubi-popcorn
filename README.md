# 🍿 Bubi's Popcorn

**Bubi's Popcorn** adalah aplikasi web mobile-first yang dirancang khusus untuk mengarsipkan daftar film yang ditonton bersama (*nonton bareng*) oleh Zald dan Micel. Aplikasi ini berfungsi sebagai buku harian digital untuk mencatat judul film, rating, ulasan pribadi, dan kenangan spesial dalam hubungan jarak jauh (LDR).

## 🚀 Fitur Utama

- **Pencatatan Film:** Simpan judul, tahun, poster, dan bulan menonton.
- **Review Personal:** Rating dan ulasan terpisah untuk Zald dan Micel.
- **Sistem Kategori:** Filter film berdasarkan siapa yang menonton (Bareng, Zald Picks, atau Micel Picks).
- **Mode Admin:** Akses terbatas untuk menambah, mengedit, atau menghapus data film dengan sistem password.
- **UI Responsif:** Desain modern dengan *dark mode*, animasi halus (Tailwind CSS), dan interaksi mobile yang intuitif.
- **Fitur Khusus:**
    - **Hero Slider:** Galeri visual untuk kenangan.
    - **Relationship Tracker:** Penghitung hari hubungan sejak 5 April 2025.
    - **Dual Timezone Clock:** Memantau waktu antara Zald dan Micel.
    - **Certified Fresh:** Badge khusus untuk film-film favorit.
    - **Copy Summary:** Memudahkan menyalin ringkasan film ke clipboard.

## 🛠️ Tech Stack

- **Frontend:** HTML5, Tailwind CSS.
- **Interaksi:** JavaScript (Vanilla JS).
- **Backend/Database:** [Supabase](https://supabase.com/) (sebagai database real-time).
- **Icons & Fonts:** Font Awesome & Google Fonts (Inter, Outfit).
